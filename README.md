# Data Structures from Scratch

Five Java assignments by James Fischer from a data structures course (TCSS 342, Winter 2026). Each one builds its core data structure by hand rather than using `java.util` collections.

| Folder | Data structure / algorithm |
|---|---|
| `hw1-burger-baron` | Custom double-ended queue (`MyDeque`) driving a burger-order parser (pair assignment) |
| `hw2-genome-population` | Genome and population evolution simulation |
| `hw3-huffman-coding` | Huffman coding tree with a custom priority queue |
| `hw4-lzw-cuckoo-hashing` | LZW compression on a custom cuckoo hash table |
| `hw5-board-puzzle` | Sliding-board puzzle solver with a custom hash table and queue (BFS) |

**Run:** `javac *.java && java Main` inside a folder.
